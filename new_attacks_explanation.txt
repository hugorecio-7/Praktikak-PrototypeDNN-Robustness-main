LinfDeepFool:

Least possible disturbance in L∞ norm

	1.-Compute Gradients & Decision Boundaries

	At each step, compute the logits (raw model outputs) for the current adversarial example.
Identify the top predicted class (correct class) and the next closest decision boundary.

	2.-Estimate the Minimal Perturbation

	Compute the gradient of the loss function for both the current class and the closest incorrect class.
Compute a small perturbation that moves the input across the decision boundary.

	3.-Iterative Refinement

	Repeat the process until misclassification occurs or the maximum number of steps is reached.
Scale the perturbation by overshoot (to ensure misclassification).

LinfAdditiveUniformNoiseAttack:

	This is a non-adaptive noise-based attack that perturbs an input by adding uniform random noise within an 𝐿∞ bound. Unlike gradient-based attacks (such as DeepFool or PGD), this attack does not require access to model gradients and is purely based on adding noise.

	1.- Generate Random Noise

Sample noise δ from a uniform distribution within a predefined bound ϵ: 𝛿∼𝑈(−𝜖, 𝜖). This means each pixel in the image is perturbed independently within the range  [−ϵ,ϵ].

	2.-Apply the Perturbation

	Compute the adversarial example by adding the noise to the original input: xadv = x+δ. The resulting adversarial example is clipped to ensure it remains within valid image bounds (e.g., [0,1] for normalized images).
	
This attack is not iterative—it simply applies noise once and tests the model.

LInfFMNAttack (Fast Minimum-Norm Attack:) 

	Is an adversarial attack that searches for the smallest perturbation in the L∞-norm that successfully misclassifies an input. 
FMN Attack is designed to be more efficient by dynamically adjusting its perturbation magnitude. Moreover, it only computes a single-step perturbation based on the gradient.

	1.-Initialization: 
	
	Starts with an initial perturbation (usually small).

	2.-Iterative Update:

	Uses gradient-based updates to find minimal perturbations. Dynamically adjusts the perturbation step size.

	3.-Stopping Criteria: 

	Stops when misclassification occurs with minimal perturbation.

LinfBasicIterative_attack

	This is an iterative gradient-based attack that perturbs an input by applying small, repeated steps within an 𝐿∞ bound. 
Unlike non-adaptive noise-based attacks, this method leverages model gradients to systematically find adversarial perturbations that maximize misclassification so it is like PGDLinfAttack.
The difference is that is a Deterministic Attack: It starts directly from the original input x without any random initialization. This means there is no randomness, the attack produces the same adversarial example every time for a given input.
